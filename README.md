# עזרא · ezra

**הבוט שעונה בפרטי לכל מי שמגיב. בלי ManyChat, ובחינם.**

קוראים לו עזרא, כי הוא עוזר.

סקיל חינמי ל-Claude Code. מישהו מגיב מילה מתחת לריל או לפוסט באינסטגרם, או עונה לסטורי, ומקבל אוטומטית הודעה בפרטי עם כפתורים.

הכל רץ דרך החיבור הרשמי של אינסטגרם, באמצעות [Zernio](https://zernio.com). הוא חינמי עד 2 חשבונות ו-10,000 הודעות בחודש.

> 🎬 **ההדרכה המלאה והחינמית, על המסך, צעד אחרי צעד:** [yoavyosha.ravpage.co.il/bot](https://yoavyosha.ravpage.co.il/bot)

## מה יש בפנים

- **הבוט:** מילה, הודעה בפרטי עם עד 3 כפתורים, ותגובה פומבית שמתחלפת כדי שלא תיראה כמו ספאם.
- **שער עוקבים (לא חובה):** מי שלא עוקב מקבל קודם בקשה לעקוב.
- **⏰ "תזכירו לי אחר כך":** מי שאין לו זמן עכשיו לוחץ, ומקבל את הלינק שוב אחרי כמה שעות.
- **📩 "שלחו לי גם למייל":** אוסף את המייל בתוך ההודעה, ומעביר אותו לניוזלטר (רב מסר, Mailchimp ועוד).
- **הפאנל:** לוח אחד שמראה כמה הגיבו, כמה קיבלו, כמה קראו, מה נכשל ומה כתבו. יש בו גם מצב הקלטה שמסתיר שמות.
- **בונה התגובות:** ממלאים טופס, רואים בטלפון בדיוק מה המגיב יקבל, ומעתיקים פרומפט אחד.
- **בדיקת בטיחות:** חוסמת את מה שמביא דיווחי ספאם:
  - מילים יומיומיות
  - חוק שעונה על כל הפוסטים
  - כפתורים שמתנגשים
  - לינק מת

```

https://github.com/YOYOAQUA/ezra

תבדוק שיש בה קובץ SKILL.md.
בסוף תגיד לי לפתוח סשן חדש.
```

אחר כך, בסשן חדש:

```
תחבר לי את עזרא
```

## מה צריך

- אפליקציית Claude למחשב (Mac או Windows), במנוי Pro ומעלה.
- אינסטגרם **מקצועי** (עסקי או יוצר). המעבר חינמי ולוקח דקה.
- חשבון Zernio חינמי, עם האינסטגרם מחובר.

## בטיחות ופרטיות

- **המפתח:** נשמר רק בקובץ `~/Ezra/.env` במחשב שלכם. הוא לא עובר בצ'אט.
- **שום דבר לא עולה לאוויר בלי "מאשר" שלכם.** כל פעולה מוצגת קודם כתצוגה מקדימה.
- **מה מסכן חשבון:** הודעות למי שלא ביקש, ולא החיבור עצמו. לכן כל חוק נצמד לפוסט אחד, ומילים נתפסות רק כשהן עומדות לבד.
- **הסקיל בא כמו שהוא, בלי אחריות.** אתם אחראים לשימוש ולכללי הפלטפורמות.
